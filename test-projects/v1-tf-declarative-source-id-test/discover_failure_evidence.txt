DISCOVER fixture diagnosis

The initial manifest used version `0.1.0`. Connector Builder output in the
Devin Sandbox and the current declarative manifests use real CDK versions; the
fixture was changed to `6.48.15`.

After that version change, standalone DISCOVER still failed for:

- Definition ID: 4507eb5e-caab-4d69-bdfa-02f2adcdcea8
- Source ID: e004b3bd-b97b-4ba6-953d-564e86d273d1
- Job ID: 005015f7-f705-4723-9a6c-080e785b5903
- Endpoint: POST https://cloud.airbyte.com/api/v1/sources/discover_schema

The job response exposed the connector traceback:

```text
Additional properties are not allowed ('__injected_declarative_manifest' was unexpected)
...
AirbyteTracedException: Additional properties are not allowed ('__injected_declarative_manifest' was unexpected)
```

The source manifest's empty connection specification had
`additionalProperties = false`. Cloud injects
`__injected_declarative_manifest` into the source configuration during
DISCOVER, so the fixture rejected the platform-injected field.

Changing the specification to `additionalProperties = true` made DISCOVER and
connection creation succeed. The connection-preservation e2e then passed with
the fixed provider, including the real manifest apply and unchanged source and
connection IDs. This evidence identifies a fixture configuration error, not a
Cloud-wide declarative-source failure.
